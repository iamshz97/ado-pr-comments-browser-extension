# PR Comments for Azure DevOps

A small browser extension that summarizes the review comments on an Azure DevOps pull request and copies them as clean Markdown, ready to paste into an LLM.

## Features

- **Summary at a glance:** unresolved thread, comment, reviewer and file counts.
- **Unresolved only:** shows Active and Pending threads. Resolved, Won't fix, Closed and By design threads are left out.
- **Anonymize names:** reviewers become `Reviewer #1`, `Reviewer #2`, … and you become `Me`. This also applies to @mentions and to names inside comment text. Excluding a reviewer doesn't renumber the others. The popup still shows the real names so you can map them back.
- **Hide my comments:** drops your own replies from the output.
- **Reviewer chips:** click one to leave that person's comments out.
- **Copy:** click the button or press `C`. Click a thread to jump to it in Azure DevOps.
- Detects who you are automatically. You can also set your name by hand in the footer.

Only threads with at least one comment from someone else are included. System comments and deleted comments are skipped.

## Install (unpacked)

1. Open `chrome://extensions` (or `edge://extensions`).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select this folder.
4. Open a PR and click the extension icon, or press `Alt+Shift+C`.

## Supported URLs

- `https://dev.azure.com/{org}/{project}/_git/{repo}/pullrequest/{id}`
- `https://{org}.visualstudio.com/[DefaultCollection/]{project}/_git/{repo}/pullrequest/{id}`
- Azure DevOps Server: `https://{host}/{collection}/{project}/_git/{repo}/pullrequest/{id}`

## How it works

The extension asks for `activeTab`, `scripting` and `storage` only, with no broad host permissions. When you open the popup, it runs a fetch inside the current Azure DevOps tab. That fetch uses your existing session to call the PR threads API (`api-version=7.1`). All filtering and formatting happen locally in `src/ado.js`. Nothing is sent anywhere else.

## Layout

```
manifest.json
src/popup.html, popup.css, popup.js   UI
src/ado.js                            URL parsing, filtering, anonymizing, Markdown (pure, no DOM)
icons/                                generated by scripts/make-icons.py
```
